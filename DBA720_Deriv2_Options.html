Part A — Black–Scholes in Excel

Build it yourself

d1 = ( LN(S/K) + (r + sigma^2/2)*T ) / ( sigma*SQRT(T) )
d2 = d1 - sigma*SQRT(T)

call = S*NORM.S.DIST(d1,TRUE) - K*EXP(-r*T)*NORM.S.DIST(d2,TRUE)
put  = K*EXP(-r*T)*NORM.S.DIST(-d2,TRUE) - S*NORM.S.DIST(-d1,TRUE)

delta(call) = NORM.S.DIST(d1,TRUE)
gamma       = NORM.S.DIST(d1,FALSE) / ( S*sigma*SQRT(T) )
vega        = S*NORM.S.DIST(d1,FALSE)*SQRT(T) / 100      per 1 percentage point of volatility
Then open DerivaGem, choose Black–Scholes European, enter the same parameters and confirm every figure. Building it once and checking it against the tool is the point — in the exam you may have only one of the two.

Enter your results

d1 = 0.0390, d2 = -0.1731; call = $3.9052, put = $4.6213; Δcall = 0.5156, Δput = -0.4844 (note Δcall − Δput = 1, which is put–call parity differentiated); Γ = 0.0376; vega = 0.1409 per percentage point. The put is worth more than the call because the option is struck $2.00 out of the money for the call holder, and the interest saved on the strike does not offset that at this maturity.

Part B — Two-step binomial tree

Price the same European call on a 2-step CRR tree over the same 0.5-year horizon.

dt = T/N
u  = EXP(sigma*SQRT(dt))        d = 1/u
p  = ( EXP(r*dt) - d ) / ( u - d )        risk-neutral probability

Terminal payoffs: MAX(S_T - K, 0)
Roll back: value = EXP(-r*dt) * ( p*V_up + (1-p)*V_down )

Enter your results

u = 1.161834, d = 0.860708, p = 0.504342. Terminal stock prices: $37.04, $50.00, $67.49. Binomial call = $3.8435 against Black–Scholes $3.9052 — a gap of $0.0617. Two steps is a crude discretisation of a continuous process; the tree converges on Black–Scholes as N rises. Build the same sheet with N = 50 and watch the difference close.

Part C — Put–call parity as an arbitrage check

Do not price the put directly. Recover it from the call using parity, and confirm it matches Part A.

p = c + K*EXP(-r*T) - S

Parity gives $4.6213, identical to the Black–Scholes put. That is not a coincidence and not a numerical accident — parity is a no-arbitrage identity, not a model. It holds whatever the option-pricing model, because violating it is a riskless profit: buy the cheap side, sell the dear side, hold to expiry. This is the same law-of-one-price logic that Lyons and Viswanath-Natraj (2023) apply to stablecoin pegs, where the arbitrage is designed rather than assumed, and the paper measures what happens to the peg when the design improves.

Interpretation

1. Vega and crypto derivatives

Vega is largest for at-the-money options with time remaining. What does that imply for anyone writing options on a cryptocurrency rather than an equity?

The writer is short vega, so value is destroyed when volatility rises — and crypto volatility is both higher and far less stable than equity volatility. Worse, the Black–Scholes framework assumes constant volatility and lognormal returns, and crypto returns are fat-tailed and volatility-clustered, so realised moves arrive in bursts that the model treats as nearly impossible. The practical consequences are that quoted implied volatilities move violently, delta-hedging a short position requires rebalancing precisely when liquidity is worst, and the model's own price is least trustworthy exactly when the position is most exposed. Nakagawa and Sakemoto (2022) make the related point on the correlation side: the co-movement structure itself changes with market uncertainty, so hedges calibrated in calm conditions are not the hedges you hold in a crisis.

2. Model risk

Both Black–Scholes and the binomial tree gave you a number. Under what circumstances would you distrust both?

Both rest on the same economics: continuous trading, no transaction costs, a known and constant volatility, a lognormal price process, and the ability to borrow and lend freely at the risk-free rate. The binomial tree is not an independent check on Black–Scholes — it converges to it, because it assumes the same world. Distrust both when trading is discontinuous (gaps, halts, exchange outages), when volatility is stochastic or jumps, when the underlying has fat tails, when funding is not available at the assumed rate, or when the position is large enough to move the market it is hedged in. Jorion's (2000) account of LTCM is precisely this failure mode: the models were not obviously wrong, the assumption that positions could be financed and unwound continuously was.
