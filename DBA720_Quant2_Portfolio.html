Excel work

  1. Compute each asset's mean and standard deviation.
  2. Build the 4×4 covariance matrix with COVARIANCE.S. Build the correlation matrix alongside it.
  3. For the equally weighted portfolio (25% each), compute the expected return as SUMPRODUCT(weights, means) and the variance as the array formula =MMULT(MMULT(TRANSPOSE(w),COV),w).
  4. Compare the portfolio's standard deviation with the average of the four individual standard deviations. The gap is the diversification benefit, and it is the whole point.
  5. Sharpe ratio = (portfolio mean − rf) / portfolio SD.
  6. For the two-asset problem below, the minimum-variance weight is w* = (σ²B − σAB) / (σ²A + σ²B − 2σAB).
Excel trap. The Data Analysis ToolPak's Covariance tool returns population covariance and fills only the lower triangle. Use COVARIANCE.S formulas so the matrix is a sample covariance matrix consistent with VAR.S, and mirror it into the upper triangle yourself.

Part B — Covariance matrix and the equally weighted portfolio

Cov(FinTech Equity,Crypto Fund) = 19.9039; Cov(Bank Index,Bond Fund) = -0.9265; Corr(FinTech Equity,Bond Fund) = -0.4573.
Equally weighted portfolio: mean 0.7505%, variance 10.4788, SD 3.2371, Sharpe 0.1392.
The average individual standard deviation is 4.3751, against a portfolio standard deviation of 3.2371. Roughly 26% of the average standalone volatility disappeared without giving up any expected return — the portfolio's mean is simply the average of the four means. That asymmetry between return (which averages) and risk (which does not) is the entire argument for diversification.

Part C — The minimum-variance two-asset portfolio

Consider only Bank Index and Bond Fund. Find the weight in Bank Index that minimises portfolio variance.

w*(Bank Index) = 0.232, so 0.7680 in Bond Fund. Portfolio variance 1.8186, standard deviation 1.3486 — below the standard deviation of either asset alone (3.3024 and 1.6272). That is only possible because their covariance is -0.9265: they move in opposite directions often enough that combining them cancels variation. This is the mechanical heart of Markowitz, and it is why the covariance matrix — not the list of individual variances — is the object that matters.

Interpretation

1. Digital assets in a mean-variance frame

The Crypto Fund has by far the highest standard deviation here. Does mean-variance optimisation handle it correctly?

Mechanically, yes — the optimiser will take the high variance and whatever covariances it has and produce a weight. Conceptually the answer is more guarded. Mean-variance optimisation assumes investors care only about the first two moments, which is defensible if returns are normal and indefensible if they are not. Cryptocurrency returns are strongly non-normal: fat-tailed, skewed and volatility-clustered, so standard deviation is an incomplete description of the risk being taken. Two further problems bite. The optimiser is notoriously sensitive to estimation error in expected returns, and crypto series are short, which makes those estimates unreliable precisely where the optimiser is most sensitive. And the covariances are not stable: Nakagawa and Sakemoto (2022) show the Bitcoin–Ether correlation is regime-dependent, falling in periods of high uncertainty, which means a matrix estimated in calm conditions describes a different world from the one in which the portfolio will be tested. The output is a number; whether it is an allocation is a separate judgement.

2. Why the covariance and not the correlation

Correlation is easier to read. Why does portfolio mathematics run on the covariance matrix instead?

Because portfolio variance is a weighted sum of covariances, not of correlations. Correlation is covariance normalised by both standard deviations, so it discards scale — it tells you the direction and tightness of co-movement but not the magnitude of the variation being shared. Two pairs can both correlate at 0.6 and contribute entirely different amounts to portfolio variance if their volatilities differ. Correlation is the right diagnostic for reading structure off a heatmap, which is what Assignment 1 asked for; covariance is the right input for computing anything. The same distinction explains why the minimum-variance hedge ratio uses Cov/Var rather than correlation alone.
